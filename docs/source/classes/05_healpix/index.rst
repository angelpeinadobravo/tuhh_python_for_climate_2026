05 · Getting to know HEALPix
================================================================================

.. note::
   The material of this class is in preparation.

Goal
----

Use simulation output on the HEALPix grid: make a map and the time series at one location.

Material available now
----------------------

- :ref:`extra_00`: the HEALPix grid and the map with ``easygems.healpix.healpix_show``; exercise 1 opens the
  ICON simulation ``ngc4008`` of the catalog.
- :ref:`extra_01`: section *Point-wise operation time-series*, the time series at one location with ``healpix.ang2pix``.

Both use ERA5; this class uses simulation output instead.

Your analysis
-------------

From this class on, you fill a page of this webpage with your plots and analysis: an example page,
``pages/05_healpix/my_page.rst`` in JupyterLab, that you change into yours. It comes with the material of the class.
