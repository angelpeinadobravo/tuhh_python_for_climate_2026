.. _class_03:

03 · Gridded data on a lon-lat grid
================================================================================

.. note::
   The material of this class is in preparation.

Goal
----

Open a netCDF file on a regular lon-lat grid and make maps and time series, with the
`E-OBS dataset <https://surfobs.climate.copernicus.eu/dataaccess/access_eobs_chunks.php>`_.

- Example: download one chunk of one variable, plot a map of one month, a map of the yearly mean, and the
  time series of the variable over Europe.
- Exercise: the same for another variable.

Material available now
----------------------

- :ref:`extra_00`: section *Netcdf Files* (ERA5 2 m temperature 2020 on a lon-lat grid), the quick plot
  with ``.plot()`` and exercise 3 (maps with cartopy).

Your analysis
-------------

From this class on, you fill a page of this webpage with your plots and analysis: an example page,
``pages/03_gridded_data/my_page.rst`` in JupyterLab, that you change into yours. It comes with the material of the class.
