Python for Climate Science
================================================================================

.. note::
   Workshop of the Max Planck Institute for Meteorology (MPI-M) for TUHH.
   This webpage runs on your laptop in the workshop container; its source is the `workshop repository <https://github.com/angelpeinadobravo/tuhh_python_for_climate_2026>`_.

The workshop teaches how to access, analyse and plot climate data with Python, using ERA5 on a
`HEALPix <https://easy.gems.dkrz.de/Processing/healpix/healpix_starter.html>`_ grid :cite:`Gorski_2005`.
Each class has a set of slides, a Jupyter notebook with exercises, and a page on this webpage where
you add what you learned.

How does a class work?
----------------------

#. Follow the class with its :doc:`slides <slides>`.
#. Start the workshop container (:doc:`getting started <contribute/intro/getstart>`) and open the notebook of the class in JupyterLab.
#. Complete the exercises at the end of the notebook.
#. Write down your lessons learned on the page of the class, save it as PDF and send it to the tutor (:doc:`how to <contribute/intro/contribsci>`).
