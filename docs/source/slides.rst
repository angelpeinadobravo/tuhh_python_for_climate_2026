Slides
================================================================================

The slides of each class are `reveal.js <https://revealjs.com>`_ decks written in Markdown in
`slides/ <https://github.com/angelpeinadobravo/tuhh_python_for_climate_2026/tree/main/slides>`_.
Press ``F`` for full screen, ``S`` for speaker notes and ``Esc`` for the overview.
