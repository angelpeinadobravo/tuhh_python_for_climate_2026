Lessons
================================================================================

Each lesson is one notebook in `examples/ <https://github.com/angelpeinadobravo/tuhh_python_for_climate_2026/tree/main/examples>`_
and one deck of :doc:`slides <../slides>`. The lessons build on each other, so follow them in order.

+--------+----------------------------------------------+-----------------------------------------------------------+
| Lesson | Notebook                                     | Topics                                                    |
+========+==============================================+===========================================================+
| 00     | ``examples/00_intake_catalog.ipynb``         | Intake catalogs, netCDF files, HEALPix vs lon-lat grids,  |
|        |                                              | quick plots                                               |
+--------+----------------------------------------------+-----------------------------------------------------------+
| 01     | ``examples/01_basics_xarray_climate.ipynb``  | Global means, point selection, limited-area analysis,     |
|        |                                              | polygons                                                  |
+--------+----------------------------------------------+-----------------------------------------------------------+
| 02     | ``examples/02_more_xarray_climate.ipynb``    | Anomalies, trends, Hovmöller diagram, jet stream,         |
|        |                                              | correlations                                              |
+--------+----------------------------------------------+-----------------------------------------------------------+
